## Идея

Мессенджер без номера телефона и без центрального сервера. Ваша личность: это ключ на устройстве, а собеседника можно добавить по QR-коду, ссылке или при встрече рядом.

## Как работает

Одно сообщение, два пути: по Bluetooth рядом, без интернета, или через Nostr-релеи на любом расстоянии. Сообщения шифруются на устройстве, прочитать их может только получатель.

## Где работает

iOS: версия 1.1. macOS, Windows, Linux и браузер: превью 0.1.8. CLI для macOS и Windows: превью. Android и CLI для Linux в разработке.
